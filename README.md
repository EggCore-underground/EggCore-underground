### Hi, I’m eggCore_

*Salut, moi c’est eggCore_.*

I build tools around things I enjoy using. A clearer interface, an easier setup, a useful detail that saves a few steps — that’s the kind of progress I’m after.

*Je crée des outils autour de ce que j’aime utiliser. Une interface plus claire, une installation plus simple, un détail utile qui évite quelques manipulations : c’est ce que j’essaie d’améliorer, version après version.*

### On the workbench

*Sur l’établi*

**Switch Control Center**  
SD card management and a homebrew workspace for Switch.  
*Gestion de carte SD et espace dédié aux homebrews Switch.*

**HOME MEDIA NETWORK**  
A local media hub for browsing a Jellyfin library and controlling compatible players at home.  
*Un centre multimédia local pour retrouver sa bibliothèque Jellyfin et piloter des lecteurs compatibles chez soi.*

**Alpine Control Center**  
Tools to plan outings, record GPS tracks and look back on your activities.  
*Des outils pour préparer ses sorties, enregistrer ses traces GPS et retrouver ses activités.*

These projects are at different stages. Some features work today; others are prototypes or still need testing on real devices. This profile introduces the workshop; it does not mean every project is publicly released.

*Ces projets sont à des stades différents. Certaines fonctions sont utilisables ; d’autres sont des prototypes ou demandent encore des essais sur de vrais appareils. Ce profil présente l’atelier : tous les projets ne sont pas encore diffusés publiquement.*

### What I’m working toward

*Ce que je cherche à améliorer*

Clearer interfaces, easier installation, useful documentation and fewer rough edges. Feedback from real use helps decide what needs attention next.

*Des interfaces plus claires, une installation plus simple, une documentation utile et moins de petits blocages. Les retours d’utilisation aident à repérer ce qui mérite d’être amélioré ensuite.*
